## 2-1. RootPassword 재설정 또는 응급 복구 진입

- RootPassword 재설정


```
1. 부팅 중 GRUB 진입 -> GRUB 메뉴 나오면 e 눌러 편집모드

esc로 진입 후 e 

2. 커널 옵션 수정

linux or linuxfi ... 맨 뒤에 rd.break 추가

3. 부팅 

ctrl+x 

4. sysroot 마운트

응급쉘 들어가지면

mount -o remount,rw /sysroot

-o(Options) : 마운트 옵션 제공
remount,rw : 임시 루트 시스템 파일들을 읽기/쓰기 모드로 전환

/sysroot: 응급 부팅 시 루트 시스템 파일들이 임시로 얹혀있는 경로

5. chroot

chroot /sysroot -> 임시 경로를 진짜 내 현재 시스템 루트로 변경

6. 새 비밀번호 입력

passwd root

7. SELinux Label 재설정

touch /.autorelabel
-> 비밀번호 파일 수정되었으므로 SELinux Label 새로 맞추는 파일
```

## 2-2. LVM Create

Create an LVM name wshare from wgroup volume group. Note the following: <br>
PE size should be 8MB <br>
LVM size should be 50 extents <br>
Format with "ext4" file system and mount it under /mnt/wshare. And it should auto mount after next reboot <br>

```
parted /dev/sda mklabel gpt
parted /dev/sda mkpart primary 1MiB 100%
parted /dev/sda set 1 lvm on

pvcreate /dev/sda1
vgcreate -s 8M wgroup /dev/sda1
lvcreate -l 50 -n wshare wgroup
mkfs.ext4 /dev/wgroup/wshare
mkdir /mnt/wshare
vi /etc/fstab -> /dev/wgroup/wshare /mnt/share ext4 defaults 0 0
mount -a
```

## 2-3. LVM - Swap Partition

Create a swap partition of 400 MB and make it available permanent

```
parted /dev/sda mkpart primary linux-swap 1MiB 401MiB
parted /dev/sda set 1 swap on
mkswap /dev/sda1
swapon /dev/sda1
swapon --show
lsblk -fp /dev/sda1
vi /etc/fstab -> UUID= ... swap swap defaults 0 0
swapon -a
```

삭제

```
swappoff /dev/sda1
/etc/fstab에서 삭제
parted -> rm 1   
```
## 2-4. resize LVM

축소

```
1. 언마운트 
umount /mnt/wshare

2. 파일 시스템 무결성 점검

e2fsck -f /dev/wgroup/wshare

3. 파일 시스템 용량 축소 (resize2fs)

resize2fs /dev/wgroup/wshare 7G

4. LV 용량 축소
lvreduce -L 7G /dev/wgroup/wshare

5. 재마운트

mount /dev/wgroup/whsare /mnt/wshare

```

확장

```
lvextend -L +500M /dev/wgroup/wshare
resize2fs /dev/wgroup/wshare
```
