Red Hat System Administration I·II에서 학습한 내용을 주제별로 다시 정리했다. 첫 글에서는 운영체제와 커널, Linux 배포판, Shell의 관계를 살펴본다.

## 1. 운영체제란?

운영체제(OS)는 애플리케이션과 하드웨어 사이에서 CPU, 메모리, 디스크, 네트워크 장치 등의 자원을 관리하는 소프트웨어다. 사용자가 저장을 요청하면 운영체제는 파일시스템과 디스크를 이용해 데이터를 기록하고, 프로그램 실행을 요청하면 CPU 시간과 메모리를 배분한다.

운영체제가 없다면 각 프로그램이 하드웨어 제어 방법을 직접 구현해야 한다. 운영체제는 공통 기능을 제공해 프로그램이 하드웨어 차이를 모두 알지 않아도 실행되도록 한다.

```text
사용자
  ↓
애플리케이션과 Shell
  ↓
운영체제(Kernel)
  ↓
CPU · Memory · Disk · Network
```

## 2. Kernel이란?

Kernel은 운영체제의 핵심 부분이다. 부팅할 때 메모리에 올라가며 다음 작업을 수행한다.

- **프로세스 관리**: 어떤 프로세스에 CPU를 얼마나 배분할지 결정한다.
- **메모리 관리**: 프로세스가 사용할 메모리를 할당하고 회수한다.
- **장치 관리**: 장치 드라이버를 통해 디스크와 네트워크 카드 등을 제어한다.
- **파일시스템 관리**: 파일을 읽고 쓰는 요청을 실제 저장장치 작업으로 연결한다.
- **권한과 보안**: 사용자 권한과 접근 정책을 검사한다.

Kernel 정보는 다음과 같이 확인할 수 있다.

```bash
uname -r
uname -a
cat /etc/os-release
```

`uname -r`은 Kernel 버전, `/etc/os-release`는 배포판과 버전 정보를 보여준다. 배포판 버전과 Kernel 버전은 서로 다른 정보다.

## 3. Linux와 배포판

엄밀히 말하면 Linux는 Kernel을 뜻한다. 실제로 설치해 사용하는 운영체제는 Linux Kernel에 패키지 관리자, 기본 명령어, 서비스, 설치 프로그램 등을 묶은 **Linux 배포판**이다.

### Red Hat 계열

- **RHEL**: 기업 환경을 위한 상용 배포판으로 기술 지원과 긴 수명 주기를 제공한다.
- **Fedora**: 새로운 기술을 빠르게 적용하는 커뮤니티 배포판이다.
- **CentOS Stream**: 다음 RHEL 마이너 버전에 들어갈 변경 사항을 먼저 확인하는 위치에 있다.
- **Rocky Linux·AlmaLinux**: RHEL과 호환되는 커뮤니티 배포판이다.

Red Hat 계열은 RPM 패키지 형식과 DNF 패키지 관리자를 주로 사용한다.

### Debian 계열

- **Debian**: 안정성과 자유 소프트웨어 원칙을 중시한다.
- **Ubuntu**: 서버와 데스크톱, 클라우드 환경에서 널리 사용된다.

Debian 계열은 DEB 패키지 형식과 APT 패키지 관리자를 주로 사용한다.

## 4. Shell이란?

Shell은 사용자가 입력한 명령을 해석해 프로그램을 실행하고 결과를 보여주는 인터페이스다. Shell이 명령을 기계어로 직접 번역하는 것은 아니다. 명령어에 해당하는 실행 파일을 찾고, Kernel이 제공하는 기능을 이용해 프로세스를 시작한다.

RHEL의 기본 Shell은 일반적으로 Bash다. 현재 Shell과 사용 가능한 Shell은 다음처럼 확인한다.

```bash
echo "$SHELL"
cat /etc/shells
```

Shell은 단순한 명령 실행 외에도 다음 기능을 제공한다.

- 변수와 환경 변수
- 명령 기록
- 와일드카드 확장
- 표준 입출력 리다이렉션과 파이프
- 조건문과 반복문을 이용한 쉘 스크립트

## 5. 명령어가 실행되는 과정

예를 들어 `ls -l /etc`를 입력하면 다음 순서로 처리된다.

1. Bash가 명령어와 옵션, 인수를 구분한다.
2. `PATH`에 등록된 디렉터리에서 `ls` 실행 파일을 찾는다.
3. Bash가 새로운 프로세스를 생성해 `ls`를 실행한다.
4. `ls`가 Kernel에 `/etc` 디렉터리 정보를 요청한다.
5. 결과가 표준 출력인 터미널에 표시된다.

```bash
type ls
which ls
echo "$PATH"
```

`type`은 명령이 별칭, 내장 명령, 실행 파일 중 무엇인지 보여주며, `PATH`는 Shell이 실행 파일을 찾는 순서를 나타낸다.

## 6. 기본 도움말 사용법

관리자는 명령어 옵션을 전부 외우기보다 시스템에서 정확한 사용법을 찾을 수 있어야 한다.

```bash
man ls
ls --help
apropos password
```

- `man`: 명령어의 매뉴얼을 연다.
- `--help`: 자주 쓰는 옵션을 빠르게 확인한다.
- `apropos`: 설명에 특정 키워드가 포함된 매뉴얼을 찾는다.

운영체제, Kernel, Shell은 서로 같은 개념이 아니다. Shell은 사용자의 명령을 받고, Kernel은 그 요청을 실제 하드웨어 자원에 연결하며, 배포판은 이 구성 요소들을 사용할 수 있는 하나의 운영체제로 묶어 제공한다.
